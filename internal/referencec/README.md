# Sensirion C reference

This directory contains the floating-point C implementation from Sensirion's
`gas-index-algorithm` release `3.2.2`, commit
`12188f5618ca7c68d22252ea7e61bb54830cd168`. It is compiled only when CGO is
enabled and is used exclusively by differential tests.
