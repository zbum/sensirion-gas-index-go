# sensirion-gas-index-go

Pure Go implementation of Sensirion's gas index algorithm. The initial
release supports the SGP40 VOC Index and is suitable for standard Go and
TinyGo programs.

This is an independent port, not an official Sensirion SDK. Its calculations
are tested against output and internal state generated by Sensirion's official
`gas-index-algorithm` C implementation.

## Install

```sh
go get github.com/zbum/sensirion-gas-index-go
```

## Use

```go
package main

import gasindex "github.com/zbum/sensirion-gas-index-go"

func main() {
	voc := gasindex.NewVOC()
	for {
		raw := readSGP40RawSignal()
		index := voc.Process(raw) // call exactly once per second
		publish(index)
	}
}
```

The processor returns `0` during its initial blackout. Normal output is in the
range `1..500`, with `100` representing the learned average environment.
Keep one processor per sensor and do not call it concurrently.

## Compatibility

- Input: unshifted SGP40 raw signal (`int32`)
- Sampling interval: 1 second
- Algorithm reference: Sensirion gas-index-algorithm 3.2.x VOC branch
- Dependencies: Go standard library only
- Minimum Go version: 1.22

The reference vector covers 20,000 samples (about 5.5 hours), including
initialization, drift, VOC events, gating, and recovery.
